# Studio操作ガイド

## Studioでできること

Studioは、スライドを見ながら最後の調整を行う画面です。ページの追加や並べ替え、
文字、発表者原稿、出典、表、グラフの編集ができます。発表時に使う専用画面も
開けます。

資料を開くには、対象の資料フォルダを指定して次のコマンドを実行します。

```bash
slide dev decks/my-deck --open
```

このリポジトリ内で直接使う場合は、次のコマンドでも開けます。

```bash
mise exec -- npm run slide -- dev decks/my-deck --open
```

画面は三つの領域に分かれています。

- 左側: ページ一覧とページ操作
- 中央: スライドの見た目を調整する場所
- 右側: 文字、原稿、出典、表、グラフの編集欄

位置、サイズ、回転の変更は自動保存されます。内容を変更する編集欄には、個別の
保存ボタンがあります。保存後に「変更を反映しています」と表示されたときは、
数秒待つと最新の表示へ切り替わります。

## ページを追加・複製・削除・並べ替えする

ページ一覧の上にあるボタンから操作します。

### ページを追加する

1. 新しいページを入れたい場所の直前のページを選びます。
2. 「追加」を押します。
3. ページの見出しを入力します。
4. 内容を確認して「実行する」を押します。

新しいページは、選択していたページの直後に追加されます。

### ページを複製する

1. 複製したいページを選びます。
2. 「複製」を押します。
3. 確認画面で「実行する」を押します。

複製したページには新しい識別名が自動で付き、元のページの直後へ追加されます。
位置やサイズの手動調整も一緒に引き継がれます。

### ページを並べ替える

移動したいページを選び、「↑」で一つ前へ、「↓」で一つ後ろへ移動します。
確認画面で対象を確かめてから実行してください。

### ページを削除する

1. 削除したいページを選びます。
2. 「削除」を押します。
3. 確認画面で対象を確かめ、「実行する」を押します。

ページ操作には取り消し機能がありません。特に削除は、確認画面のページ名を
必ず確認してください。資料には最低一ページが必要なため、最後の一ページは
削除できません。

ページ操作のボタンが押せない場合は、変更の反映中である可能性があります。
数秒待っても有効にならないときは、「ページ操作ができないとき」を確認してください。

## 発表者原稿と出典を編集する

右側の「発表者原稿・出典」を開いて編集します。

1. 左側で対象のページを選びます。
2. 「発表者原稿」に、そのページで話す内容を入力します。
3. 必要に応じて「出典を追加」を押します。
4. 出典の資料名を入力し、Webページの場合はURLも入力します。
5. 「原稿と出典を保存」を押します。

出典名は必須です。URLは省略できます。URLを入力する場合は、`http://`または
`https://`で始まるWebページを指定します。

保存した原稿と出典は発表者画面に表示されます。発表者原稿は、PPTXを書き出した
ときの発表者ノートにも反映されます。

## 表を編集する

1. 中央のスライド、または右側の要素一覧から表を選びます。
2. 右側に表示される「表のデータ」を開きます。
3. 変更したいセルを直接編集します。
4. 必要に応じて、値の種類、背景色、文字位置、横・縦の結合数、数値の表示形式を選びます。
5. 列幅や行の高さを調整し、必要に応じて行や列を追加・削除します。
6. 「データを保存」を押します。

削除できるのは末尾の行または末尾の列です。表の見出し行が設定されている場合は、
保存後も見出しとして維持されます。

横・縦の結合数は、現在のセルから何個分をまとめるかを表します。ほかの結合済みセルと
重ならないように指定してください。結合セルが一つでもある間は、行・列の追加と削除が
できません。構造を変えるときは、すべての横結合数と縦結合数を1へ戻して一度保存し、
その後に行・列を変更してください。

列幅と行の高さは比率ではなく、スライド上の大きさを表す数値です。列幅を入力する場合は
すべての列へ入力し、合計を表全体の幅に合わせます。行の高さも同様にすべての行へ入力し、
合計を表全体の高さに合わせます。中央の画面で表全体を拡大・縮小すると、入力済みの列幅と
行の高さも同じ比率で調整されます。表は最後の1行・1列を削除できず、空の表は保存できません。

数値の表示形式を使う場合は、値の種類を「数値」にし、整数、小数、パーセント、日本円から
選びます。表示形式は見た目を揃えるためのもので、PowerPoint内の計算式にはなりません。

CSVやJSONなど別ファイルから読み込んだ表をStudioで保存すると、その時点で表示
されている値が資料本体へ保存されます。それ以降は、元の別ファイルを変更しても
表へ自動では反映されません。

## グラフを編集する

1. 中央のスライド、または右側の要素一覧からグラフを選びます。
2. 右側に表示される「グラフのデータ」を開きます。
3. 系列名、項目名、数値、色を編集します。
4. 複合グラフでは、系列ごとに棒、折れ線、面を選びます。
5. 必要に応じて、横軸・縦軸の名前と単位、凡例の表示位置、値・項目名ラベルを設定します。
6. 必要に応じて、項目や系列を追加・削除します。
7. 「データを保存」を押します。

色を指定する場合は、`#1769ff`のような形式で入力します。色を空欄にすると、
資料のテーマに設定された色を使います。グラフには最低一つの系列が必要で、各系列にも
最低一つの項目と数値が必要です。円グラフとドーナツグラフは一系列だけで作成し、
各項目を一つの扇形として表示します。ブラウザの凡例には各項目名と、その扇形と同じ色が
表示されます。円・ドーナツの値は0以上にし、少なくとも一つは0より大きい値にしてください。

棒、折れ線、面、レーダー、積み上げ、複合グラフを複数系列で作る場合は、すべての系列で
同じ項目名を同じ順番にします。散布図は数値の横軸を使うため、複合グラフには混在できません。

散布図では、各系列の「項目名」へ有限の数値を必ず入れます。この値が横軸になり、系列ごとに
異なる横軸の値を入力しても、書き出したPPTXで系列ごとの値を維持します。

軸の設定は名前と単位までです。目盛りの最小・最大値、第二軸、ラベル一つずつの位置調整は
現在の編集画面には含まれていません。

別ファイルから読み込んだグラフも、Studioで保存した時点の値が資料本体へ保存され、
元の別ファイルとは自動で同期しなくなります。

## 発表者画面を使う

編集画面の右上にある「▶」を押すと、発表者画面が別ウィンドウで開きます。

発表者画面には次の情報が表示されます。

- 現在のページ
- 次のページのプレビュー
- 発表者原稿と出典
- 発表開始からの経過時間

「一時停止」「再開」「リセット」で経過時間を操作できます。「前へ」「次へ」のほか、
キーボードの矢印キー、Page Up、Page Downでもページを移動できます。スペースキーでも
次のページへ進めます。

編集画面と発表者画面を同じブラウザで開いている場合は、選択中のページが互いに
同期します。発表者原稿が見える画面なので、このウィンドウを観客側の画面へ共有
しないでください。

発表者画面が開かない場合は、ブラウザが別ウィンドウを止めている可能性があります。
このページのポップアップを許可してから、もう一度「▶」を押してください。

## 競合を知らせる表示が出たとき

Studioは、ほかの画面や編集ソフトで行われた変更を勝手に上書きしません。次のような
表示が出たときは、いったん最新の内容を読み直します。

- 「別の場所で資料が更新されています」
- 「保存の直前に資料が更新されました」
- 「直前の変更を反映中です」

「直前の変更を反映中です」は通常の待機表示です。まず数秒待ってください。
そのまま変わらない場合や、別の場所での更新が案内された場合は、次の順で対処します。

1. 入力途中の文章があれば、念のため手元へコピーします。
2. ブラウザを再読み込みします。
3. 最新のページ内容を確認します。
4. 必要な変更だけをもう一度入力して保存します。

再読み込み後も反映が終わらない場合は、Studioを起動した画面で処理が止まっていないか
確認し、`slide dev`をいったん終了してから再起動します。

## ページ操作ができないとき

ページの追加、複製、削除、並べ替えは、資料本体が一つの`deck.mdx`にまとまった
新しい形式で利用できます。ボタンが押せないときは、次を順に確認します。

1. 保存直後であれば、数秒待ちます。
2. ブラウザを再読み込みします。
3. 資料フォルダに`deck.mdx`があることを確認します。
4. 古い分割形式の資料であれば、新しい単一ファイル形式への移行を依頼します。

古い形式の資料も表示と位置調整はできますが、Studioからのページ操作や発表者原稿の
保存には対応していません。
