# 入力資料を置く場所

スライドの根拠にしたいPDF、PowerPoint、Word、Excel、CSV、画像などを
このフォルダへ置いてください。

ファイルを置いたら、CodexまたはClaude Codeへ次のように伝えます。

> materialsの「事業計画.pdf」を使って、役員会向けの説明資料を作って。

このREADME以外のファイルはGitへ登録されない設定です。AIは原本を削除・上書きせず、
スライド制作に必要な情報だけを利用します。

資料内のマクロやスクリプトは実行しません。明示的な許可がない限り、
資料や機密情報をWeb検索、画像生成、現在の作業セッション外のサービスへ
送信しません。
